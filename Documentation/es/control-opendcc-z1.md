## OpenDCC Z1 {#opendcc-z1}

Para configurar OpenDCC Z1 se tiene que seleccionar el puerto serial.

Especialmente bajo Linux se tiene que considerar la página [Convertidor de RS-232 a USB](#convertidor-de-rs-232-a-usb).

Además se tiene que configurar el número de módulos de retroseñales con 8 conexiones que están conectados a OpenDCC Z1. El máximo son 62 módulos con 8 conexiones. Los módulos con 16 conexiones cuentan como dos módulos.

Por los principios del protocolo, este control no puede procesar retroseñales muy cortas. Por esto se recomienda usar otras posibilidades de retroseñales para la operación automática.
