## HSI-88 RS232 {#hsi-88-rs232}

RailControl solamente soporta el HSI-88 RS232. La versión USB no está soportada.

Para configurar HSI-88 se tiene que seleccionar el puerto serial.

Especialmente bajo Linux se tiene que considerar la página [Convertidor de RS-232 a USB](#convertidor-de-rs-232-a-usb).

Además se tiene que configurar el número de módulos de retroseñales con 8 conexiones que están conectados a HSI-88. El máximo son 62 módulos con 8 conexiones. Los módulos con 16 conexiones cuentan como dos módulos.
