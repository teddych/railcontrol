## Uhlenbrock Intellibox {#uhlenbrock-intellibox}

Para configurar Uhlenbrock Intellibox se tiene que seleccionar el puerto serial.

Especialmente bajo Linux se tiene que considerar la página [Convertidor de RS-232 a USB](#convertidor-de-rs-232-a-usb).

Además se tiene que configurar el número de módulos de retroseñales con 8 conexiones que están conectados a Intellibox. El máximo son 104 módulos con 8 conexiones. Los módulos con 16 conexiones cuentan como dos módulos.

Por los principios del protocolo, este control no puede procesar retroseñales muy cortas. Por esto se recomienda usar otras posibilidades de retroseñales para la operación automática.
