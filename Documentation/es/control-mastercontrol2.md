## Tams MasterControl 2 {#tams-mastercontrol-2}

Para configurar Tams MasterControl 2 se tiene que seleccionar la dirección IP del dispositivo. Para configurar una dirección IP se tienen que consultar las instrucciones de uso del MasterControl 2.

Además se tiene que configurar el número de módulos de retroseñales con 8 conexiones que están conectados a MasterControl. El máximo son 104 módulos con 8 conexiones. Los módulos con 16 conexiones cuentan como dos módulos.

Por los principios del protocolo, este control no puede procesar retroseñales muy cortas. Por esto se recomienda usar otras posibilidades de retroseñales para la operación automática.
