# RailControl Screenshots

List generator and image generator for the popups (all tabs, all languages) and the main menu buttons of the RailControl web UI.
The images have the same size as the ones in `Documentation` (626 x 626 px for a popup).

## Files

| File                   | Purpose                                                                                            |
|------------------------|----------------------------------------------------------------------------------------------------|
| `screenshot_tool.py`   | The tool with the actions `list`, `check` and `images`.                                            |
| `screenshot_tool.html` | Browser side API (discovers popups and tabs, opens them, switches the language). Used by the tool. |
| `images.csv`           | The image list: which images are created, from which popup URL and tab.                            |
| `requirements.txt`     | Python requirements (Selenium).                                                                    |

## Requirements

- RailControl is running (default `http://127.0.0.1:8082`).
- Firefox. Selenium Manager downloads `geckodriver` automatically.
- Python 3 with Selenium:

  ```sh
  python3 -m pip install --user -r tools/screenshots/requirements.txt
  ```

Works on Linux, on Windows and within Cygwin (using the Windows Firefox). Firefox runs headless.

## Workflow

### 1. Create or update the list

```sh
python3 tools/screenshots/screenshot_tool.py list
```

- Crawls the web UI: all popups found in `onclick` handlers of the main page, of the layout context menus
  and, recursively, of the popups themselves, and all tabs of each popup.
- Existing rows are **kept unchanged**, so image names, types, URLs and notes can be edited by hand.
- Empty URLs are filled in, newly found popups/tabs are appended with a default name (`<command>[_<tab>]`),
  newly found buttons of the main menu with `menu_<command>`.
- Rows that are no longer found in the web UI are reported.
- The column `documentation` is recomputed (see `check`).

### 1b. Compare the list with the documentation

```sh
python3 tools/screenshots/screenshot_tool.py check
```

- Recomputes only the column `documentation`. Needs neither RailControl nor Firefox nor Selenium.

### 2. Create the images

```sh
python3 tools/screenshots/screenshot_tool.py images
python3 tools/screenshots/screenshot_tool.py images --languages all
python3 tools/screenshots/screenshot_tool.py images --languages de,es --filter '^tracks_'
python3 tools/screenshots/screenshot_tool.py images --languages all --out-dir Documentation
python3 tools/screenshots/screenshot_tool.py images --type button --out-dir Documentation
```

- Creates one image per popup row and language as `<out-dir>/<lang>/<image>_<lang>.png` (as in `Documentation`).
- Creates one image per button row (language independent) as `<out-dir>/<image>.png` (as in `Documentation`).
  Buttons hidden by the window width (e.g. the config menu button) are made visible temporarily.
- With `--out-dir Documentation` the images of the documentation are updated directly.
- The language is switched with the real settings form, so all other settings keep their values.
  The original language is restored at the end.
- No other form is ever submitted.

## Image list (`images.csv`)

Semicolon separated, UTF-8:

| Column          | Meaning                                                                                      |
|-----------------|----------------------------------------------------------------------------------------------|
| `image`         | Base name of the image                                                                       |
| `type`          | `popup`, `button`, `other` or `external` (see below)                                         |
| `documentation` | Generated by `list` and `check`, except `excluded` (set by hand): `yes`, `no`, `mismatch`, `missing` or `excluded` (see below) |
| `command`       | Popup command (`cmd=...`) or button command (button id `skip_<command>`)                     |
| `tab`           | Tab inside the popup, empty if the popup has no tabs                                         |
| `url`           | Popup URL. Empty: filled in by `list`. `manual`: has to be set by hand (skipped until then). Unused for buttons. |
| `notes`         | Free text                                                                                    |

### Column `type`

| Value      | Meaning                                                                         | Created by `images`              |
|------------|---------------------------------------------------------------------------------|----------------------------------|
| `popup`    | Popup (or tab of a popup) of the web UI, one image per language                 | `<out-dir>/<lang>/<image>_<lang>.png` |
| `button`   | Button of the main menu, one image for all languages                            | `<out-dir>/<image>.png`          |
| `other`    | Other image of the web UI (e.g. layout context menu), one image per language    | no, created by hand              |
| `external` | Image not coming from RailControl (e.g. screenshot of a control)                | no, created by hand              |

Old lists without this column are converted automatically (type guessed from URL and notes).

### Column `documentation`

Compares the list with `Documentation` (`<lang>/<image>_<lang>.png` in any language, buttons `<image>.png`):

| Value      | Meaning                                                                                                   |
|------------|-----------------------------------------------------------------------------------------------------------|
| `yes`      | The image exists in the documentation                                                                     |
| `no`       | The image exists in the documentation, but does not come from RailControl (type `external`)               |
| `mismatch` | The image exists in the documentation with another name (see console output for the name). Resolve by renaming the image in the list. |
| `missing`  | The image does not exist in the documentation                                                             |
| `excluded` | **Set by hand:** the image is not needed in the documentation. Never recomputed, takes no part in the mismatch detection. `unneeded` is accepted as well and converted to `excluded`. New rows containing `askdelete` get `excluded` by default. |

A `mismatch` is detected by the hint `documentation: <name>.png` in the notes or guessed by comparing the
names with the documentation images not referenced by the list (e.g. `menu_locolist` ↔ `menu_loco`).
Documentation images not referenced by any row are reported.

For each `mismatch`, a suggestion how to resolve it is written into `notes`, e.g.
`[suggestion: the documentation uses menu_loco.png. Rename image 'menu_locolist' to 'menu_loco' in this list or rename the documentation file and its references to 'menu_locolist']`.
The part `[suggestion: ...]` is generated: it is removed and recreated by every `list` and `check`, the rest of the notes is kept.

Popup rows without a URL starting with `/?cmd=` are skipped by `images`.

The URLs reference objects of the current database (e.g. `loco=2`). To show a specific object, edit the URL.

## Options

| Option          | Action          | Default                        | Description                                                                         |
|-----------------|-----------------|--------------------------------|-------------------------------------------------------------------------------------|
| `--list`        | all             | `tools/screenshots/images.csv` | Image list                                                                          |
| `--doc-dir`     | all             | `<repository>/Documentation`   | Documentation directory used for the column `documentation`                         |
| `--base-url`    | `list` `images` | `http://127.0.0.1:8082`        | URL of RailControl                                                                  |
| `--html-dir`    | `list` `images` | `<repository>/html`            | html directory served by RailControl (the crawler page is copied there temporarily) |
| `--firefox`     | `list` `images` |                                | Path to the Firefox binary                                                          |
| `--no-headless` | `list` `images` |                                | Show the Firefox window                                                             |
| `--depth`       | `list`          | `3`                            | Maximum nesting depth of popups                                                     |
| `--languages`   | `images`        | `current`                      | `current`, `all` or comma separated keys or codes (`0`/`en`, `1`/`de`, `2`/`es`)    |
| `--type`        | `images`        | `all`                          | `all`, `popup` or `button`                                                          |
| `--filter`      | `images`        |                                | Regular expression matched against the image name                                   |
| `--out-dir`     | `images`        | `<repository>/screenshots`     | Output directory                                                                    |
| `--name`        | `images`        | `{lang}/{image}_{lang}.png`    | File name pattern of popups. Placeholders: `{lang}` `{image}` `{command}` `{tab}`   |
| `--button-name` | `images`        | `{image}.png`                  | File name pattern of buttons. Placeholders: `{image}` `{command}`                   |
| `--settle`      | `images`        | `700`                          | Milliseconds to wait after a popup has been loaded                                  |
